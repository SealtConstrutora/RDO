Ativar os cadastros compartilhados

Esta configuração é feita uma vez pelo responsável pelo site. Depois, publique o arquivo configurado no GitHub para todos usarem a mesma conexão.

  1. Abra seu projeto no Supabase.
  2. Baixe o SQL abaixo e execute todo o conteúdo em SQL Editor → New query → Run. Ele cria tabelas próprias para este RDO.
  3. Copie a URL do projeto e a chave pública Publishable (ou anon) do painel.
  4. Preencha os campos e baixe o HTML configurado. Substitua o index.html do seu GitHub e mantenha a imagem sealt.png.
  5. No site publicado, entre em Cadastro com a senha padrão e use Importar cadastros deste navegador se quiser aproveitar as obras e funções antigas.

Use somente a chave pública. Nunca use uma chave secret ou service_role.

Fotos e PDFs continuam sendo preparados no aparelho; esta integração compartilha os cadastros e a numeração. Números são reservados antes da montagem do PDF; em caso de falha, tente novamente no mesmo formulário para reutilizar a reserva.

Obras, funções e sequência compartilhadas entre todos os aparelhos. É necessário estar conectado à internet para emitir um novo RDO.

Acesso ao Cadastro

A senha é verificada no banco de dados. As alterações do Cadastro valem para todos os aparelhos.

Obras

Se já existem 25 relatórios desta obra, informe 26. Cada obra tem sua própria sequência.

Edite o próximo número e clique em Salvar número. Isso ajusta a sequência dos novos RDOs, sem alterar os PDFs já gerados.
